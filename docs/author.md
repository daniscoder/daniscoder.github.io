# Об авторе

Danis Arslanov, обработчик сейсморазведочных данных. Программы на этом сайте
выросли из работы: каждая закрывает шаг, который руками делать долго или в

## Опыт

- **Обработка сейсморазведочных данных:** Geovation, Omega, Пикеза.
- **Просмотр кубов и разрезов:** OpendTect, Petrel.
- **Проектирование съемки:** Mesa.
- **Карты и поверхности:** Surfer.
- **Разработка:** Python - когда результат нужен быстро; Qt/C++ - для
  настольных программ.

## Что можно заказать

- **Утилиту под вашу задачу** - такую же небольшую программу, как на этом сайте:
  под формат выгрузки вашей системы обработки, под порядок работы партии или
  центра обработки. Для Windows и Linux, одним файлом, без установки.
- **Автоматизацию рутины** - скрипты для пакетной обработки файлов, конвертеры
  форматов, проверку и сверку данных.
- **Доработку программ с сайта** - новый формат входных данных, новый параметр,
  вывод под вашу систему.
