# autocrop

**Пакетная автоматическая обрезка скриншотов**

Утилита предназначена для пакетной обработки снимков экрана при подготовке
материалов для отчетов и презентаций. Поддерживаются изображения с
сейсмограммами, разрезами, слайсами, схемами, картами и спектрами.

Для каждого файла программа сама определяет область полезного изображения:
отбрасывает заголовок окна, панели инструментов, полосы прокрутки, строку
состояния и пустые поля. Рамка обрезки рассчитывается отдельно для каждого
снимка, поэтому в одной папке могут лежать окна разных программ и разного
размера.

На выходе получается готовая картинка в одном из вариантов:

- только изображение;
- изображение с осями;
- изображение с полным оформлением: заголовками, названиями осей и палитрой.

Если все снимки сделаны в одном окне и в одном масштабе, рамку можно задать
вручную: один раз нарисовать ее мышью на предварительном просмотре, и она будет
применена ко всем файлам. Слишком крупные картинки при сохранении можно
пропорционально уменьшить до заданного размера, а формат результата выбрать
любой из PNG, JPG и BMP.

Полученные файлы можно сразу вставлять в отчеты и презентации.

## Варианты обрезки

На каждом снимке программа находит сразу три рамки и показывает их на
предварительном просмотре. Выбранный вариант выделен толстой линией.

- **Картинка** (зеленая рамка) - только поле данных, точно по его границе. Если
  у карты нет рамки, граница определяется по осям и крайним точкам данных.
  Полоса прокрутки внутри поля отрезается всегда.
- **С осями** (красная рамка) - к полю данных добавляются подписи делений над
  ним и под ним, сколько бы рядов там ни было, и значения вертикальной оси. По
  ширине рамка заканчивается на краю этих значений, поэтому названия рядов слева
  в нее не попадают.
- **С оформлением** (синяя рамка) - все, что окружает изображение: заголовки,
  названия осей, палетки, таблицы и подписи над картой.

Для вариантов с осями и с оформлением задается **отступ** - поле в несколько
пикселов вокруг рамки. Картинка без осей режется точно по границе, без отступа.

## Ручной режим

Когда все снимки одинаковые - одно и то же окно в одном масштабе, - рамку удобнее
задать самому. На вкладке «Вручную» указывается прямоугольник в пикселах снимка:
X, Y, ширина и высота. Он вырезается из каждого файла, а то, что выходит за край
снимка, просто отбрасывается.

Проще всего нарисовать рамку мышью прямо на предварительном просмотре: если
потянуть за край или угол, меняется размер, если изнутри - рамка сдвигается, а
щелчок вне рамки начинает новую. Стрелки на клавиатуре сдвигают рамку на 10
пикселов, со Shift - на один.

## Результат и сжатие

Обрезанные снимки сохраняются под прежними именами в папку результата. По
умолчанию это папка `cropped` рядом со снимками, но можно выбрать любую. Если
поле папки оставить пустым, результат ляжет рядом с исходным файлом, а к имени
добавится `_cr`. Исходные снимки программа никогда не перезаписывает.

Формат результата - как у исходного снимка или PNG, JPG, BMP. Для снимков окон
лучше всего подходит PNG: файл получается меньше, а качество не теряется.
Галочка «Палитра 256 цветов» в окне «Настройка...» уменьшает PNG еще в 2-4 раза.
Там же задается качество JPG: ниже 85 мелкие подписи на снимке заметно
размываются.

Параметр «Сжать до» ограничивает длинную сторону результата: если картинка
больше заданного размера, она пропорционально уменьшается. Под предварительным
просмотром виден итоговый размер - уже после обрезки и сжатия.

Обрабатывать можно выделенные снимки или сразу все снимки папки. Работа идет
параллельно на всех ядрах процессора.

## Работа с файлами

Левая часть окна - обозреватель папки. Снимки в нем показываются миниатюрами,
списком или подробным списком с размером изображения, объемом файла и датой.
Папки открываются двойным щелчком.

Файлы и папки можно копировать, вырезать и вставлять, в том числе между
программой и Проводником, переименовывать (F2), удалять в корзину и создавать
новые папки. Все действия доступны кнопками над списком, в меню по правой кнопке
мыши и привычными сочетаниями клавиш.

## Запуск из командной строки

Если запустить программу с аргументами, она работает без окна. Это удобно для
обработки из скриптов:

```
autocrop снимок.png папка_со_снимками -k axes -f png -o cropped
```

Основные ключи:

- `-k all|axes|image` - вариант обрезки: с оформлением, с осями или только
  картинка;
- `-o` - папка результата; `-o ""` - рядом со снимком, с `_cr` в имени;
- `-f png|jpg|bmp` - формат результата;
- `-m` - отступ;
- `-q` - качество JPG, `--palette` - PNG с палитрой 256 цветов;
- `--box X Y W H` - ручной режим: вырезать этот прямоугольник из всех снимков;
- `--max-side` - сжать до заданной длинной стороны.

Полный список ключей выводит `autocrop -h`.
