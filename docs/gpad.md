# gPad

**Текстовый редактор для геофизика**

Редактор сочетает стандартные возможности работы с обычным текстом и
специализированные инструменты для текстовых форматов, используемых в
сейсморазведке: геометрии наблюдений SPS, таблиц скоростей, статических поправок
и координат. Предусмотрен режим работы с колонками и набор функций для файлов SPS.

Такие файлы устроены колонками, и редактируются они по колонкам: изменения
применяются к колонке целиком, а не к каждой строке по отдельности.

## Обычный текст

Для работы с обычным текстом редактор предоставляет стандартный набор
возможностей:

- одновременное открытие нескольких файлов во вкладках, список недавних файлов,
  открытие нескольких файлов на одной странице;
- поддержка кодировок и концевиков строк Windows, Unix и Mac;
- поиск и замена, в том числе по регулярным выражениям и в пределах выделенного
  фрагмента;
- закладки: десять нумерованных и свободные; предусмотрено удаление всех строк с
  закладкой или, наоборот, без нее;
- сортировка строк, в том числе многоуровневая по колонкам;
- удаление пустых строк, дубликатов и строк по маске; смена регистра; разбиение
  крупного файла на части.

## Колонки

Режим колонок и блоковое выделение дополняют стандартные возможности редактора
при работе с колоночными форматами. Для колонки доступны следующие операции:

- набор текста с клавиатуры прямо в колонку: набранное вводится сразу во все
  строки колонки ниже курсора, в той же позиции;
- вставка, удаление, вырезание и смещение колонки; выравнивание влево, вправо или
  по центру;
- вставка нумерации с заданными первым номером, шагом и ведущими нулями;
- арифметические операции над колонкой и формирование сводки: количество
  значений, минимум, максимум, среднее и сумма;
- вставка колонки из буфера обмена или разбиение текста с разделителями на
  колонки фиксированной ширины;
- выбор строк по значениям в колонке.

## SPS

Для файлов SPS предусмотрен отдельный набор инструментов:

- формат SPS настраивается: ревизия, позиции полей, символ комментария. Есть
  стандартные форматы Rev 0 и Rev 2.1 и перевод между ними;
- сортировка, поиск текущего ПВ в файлах S и X, выделение и очистка колонок SPS
  R, S и X;
- работа с шапками: убрать комментарий, привести к стандарту, вставить
  дополнительную информацию - юлианский день, время, индексы, коды;
- проверка нумерации: унифицировать номера записей, показать пропущенные;
- удаление перестрелов ПВ;
- построение SPS S и R по SPS X, а для 2D - SPS R и S по координатам точек
  излома профиля;
- база данных ПП и ПВ с импортом и экспортом через текст, Excel или буфер
  обмена. Из нее обновляются SPS-файлы: координаты из топографических данных,
  статические поправки, глубины и вертикальные времена скважин, расстановки 2D;
- экспорт в библиотеку Geocluster.

## Скорости

Встроенный конвертор переводит скоростные форматы LVI, Handvel и V5 друг в
друга в любом направлении.
