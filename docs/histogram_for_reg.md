# histogram_for_reg

**Анализ распределения удалений для регуляризации 3D**

Утилита строит диаграмму распределения удалений и предназначена для планирования
регуляризации 3D-сейсмических данных.

Программа разбивает удаления на классы, отображает их в виде диаграммы и
сохраняет рядом с входным файлом таблицу классов. Полученную таблицу можно
использовать в качестве входных данных для регуляризации 3D.

Классы удалений строятся одним из двух способов:

- с постоянным шагом - все классы одинаковой ширины;
- со ступенчатым шагом - удаления делятся на зоны, внутри зоны шаг постоянный, а
  от зоны к зоне меняется. Зоны программа подбирает сама так, чтобы получилось
  заданное число классов, а трассы распределились по ним как можно равномернее.

## Входные данные

На вход подается текстовый файл в две колонки: удаление (SOURCE_DETECT_DIST) и
количество трасс (STACK_WORD). Колонки разделены пробелами, их число не важно.

```
 SOURCE_DETECT_DIST.G STACK_WORD
            -3976.000          2
            -3975.000          1
            -3974.000          3
```


Первая строка пропускается, только если в ней не числа, поэтому файл без
заголовка читается целиком. Знак удаления означает сторону от пункта
возбуждения, так что удаления берутся по модулю, а трассы с одинаковым удалением
суммируются.

## Постоянный шаг

Все классы имеют одинаковую ширину. Ближние удаления можно собрать в первый класс
шириной в несколько шагов, а дальние - в последний класс, начиная с заданного
удаления.

![Постоянный шаг](img/histogram_const.png)

## Ступенчатый шаг

Удаления делятся на зоны: внутри зоны шаг постоянный, а от зоны к зоне он
меняется. Обычно у ближних удалений шаг крупный, в плотной середине мелкий, а к
дальним снова крупнее. В каждом классе получается примерно целевое число трасс,
как при классах равной населенности, но классы внутри зоны остаются регулярными.
Поэтому артефактов миграции Кирхгофа меньше, чем когда у каждого класса своя
ширина.

![Ступенчатый шаг](img/histogram_step.png)

Параметры подбора:

- **Количество классов удалений** - сколько классов будет на диаграмме. Если
  остальные параметры позволяют, классов получается ровно столько; иначе
  программа предупредит и возьмет ближайшее возможное число.
- **Базовый шаг** - шаги зон подбираются кратными ему. Чем он меньше, тем ближе
  классы к равной населенности, но тем дольше идет подбор.
- **Зон не больше** и **классов в зоне не меньше** - ограничения на подбор.

Кнопка «Подобрать» заполняет таблицу зон «от удаления - шаг» по данным: зоны
подбираются перебором так, чтобы число трасс в классах как можно меньше
отклонялось от целевого. Таблицу можно поправить вручную и построить диаграмму
заново.

## Результат

Программа открывает окно с диаграммой - ее можно приблизить и сохранить
картинкой - и записывает текстовый файл рядом с входным: `<имя>_<шаг>.txt` для
постоянного шага и `<имя>_step<классы>.txt` для ступенчатого. В файле четыре
колонки: первое удаление класса, последнее удаление, центр класса и количество
трасс.

```
    0   36   25   4080
   37   61   50   4089
   62   86   75  12217
```


Размер окна и значения всех полей запоминаются между запусками.
