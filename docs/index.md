# Программы для сейсмообработки

Небольшие настольные программы для рутины обработки сейсморазведочных данных
2D/3D. Все бесплатны, работают на Windows и Linux и ничего не требуют ставить:
программа - один файл, который достаточно скачать и запустить.

<div class="grid cards" markdown>

-   :material-chart-histogram:{ .lg .middle } **[histogram_for_reg](histogram_for_reg.md)**

    ---

    Диаграмма распределения удалений и разбиение удалений на классы для
    регуляризации: постоянный шаг или ступенчатый - зоны с постоянным шагом,
    подобранные под заданное число классов.

-   :material-vector-polygon:{ .lg .middle } **[polygon](polygon.md)**

    ---

    Полигон границы съемки по выгрузке бинов или по точкам SPS: контур по
    крайним точкам или буфер с отступом, полигон на каждую площадь, файл для
    обработки или для Surfer.

-   :material-layers-triple:{ .lg .middle } **[lmoToXY](lmotoxy.md)**

    ---

    Слоистая модель верхней части разреза по первым вступлениям: границы
    слоев в удалениях и скорости слоев на каждом ПВ, координаты из SPS -
    для расчета статических поправок.

</div>

## Как запустить

Скачайте со страницы программы файл для своей системы. Установки нет: файл можно
положить куда угодно и запускать оттуда. При первом запуске программа
распаковывается во временный каталог, поэтому первый старт на пару секунд
дольше.

**Windows.** Двойной щелчок по `.exe`. Программы не подписаны сертификатом, и
Windows при первом запуске может показать окно SmartScreen «Система Windows
защитила ваш компьютер» - нажмите «Подробнее», затем «Выполнить в любом случае».

**Linux.** Файл без расширения. Если он пришел архивом или с сетевой папки
Windows, право на выполнение теряется - верните его и запустите:

```bash
chmod +x polygon
./polygon
```

Qt лежит внутри файла, но окну нужны системные библиотеки. На рабочей машине с
графикой они уже есть, на голой их может не быть - в Debian и Ubuntu это
`libgl1`, `libxkbcommon-x11-0` и `libxcb-cursor0`.

В каждой программе есть кнопка «Справка» с порядком работы и описанием всех
параметров и кнопка «О программе» с номером версии.
