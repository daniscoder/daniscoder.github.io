# Утилиты сейсмообработчика

Небольшие программы, которые я написал для своей работы в обработке
сейсморазведочных данных 2D и 3D. Они экономят время на рутине и помогают:

- **подготовить параметры обработки** - классы удалений для регуляризации 3D,
  полигон границы съемки, модель верхней части разреза для статических поправок;
- **проверить полевые данные** - поправить и сверить файлы SPS, оценить качество
  отстрела по листингам регистрации;
- **оформить результат** - обрезать снимки экрана с разрезами, картами и
  спектрами для отчета или презентации, сразу целой папкой.

Все программы бесплатные, и ставить их не нужно: программа - один файл, скачали
и запустили. Почти все есть и для Windows, и для Linux, включая старые системы
вроде CentOS 7. Только ListQC, самая давняя из них, работает лишь на Windows.
Если что-то не запускается - смотрите [«Как запустить»](#run) ниже.

## Как запустить { #run }

Скачайте со страницы программы файл для своей системы. Установки нет: файл можно
положить куда угодно и запускать оттуда. При первом запуске программа
распаковывается во временный каталог, поэтому первый старт на пару секунд
дольше.

**Windows.** Двойной щелчок по `.exe`. Программы не подписаны сертификатом, и
Windows при первом запуске может показать окно SmartScreen «Система Windows
защитила ваш компьютер» - нажмите «Подробнее», затем «Выполнить в любом случае».

**Linux.** Нужна система с glibc 2.38 или новее: Ubuntu 24.04 и новее, Debian
13, Fedora 39 и новее, RHEL, Rocky и Alma 10. На более старых - Ubuntu 22.04,
Debian 12, RHEL, Rocky и Alma 8 и 9, Astra Linux - программа не запустится и
напишет
``version `GLIBC_2.38' not found``. Свою версию покажет `ldd --version`.

Для старых систем у части программ есть отдельная сборка - кнопка «Linux
(старые системы)» на странице программы. Она на Qt5, собрана на CentOS 7 (glibc 2.17)
и запускается на ней и на всех системах новее. Такая сборка есть у
histogram_for_reg, polygon, lmoToXY и autocrop.

На новых системах с Wayland (KDE, GNOME) у сборки для старых систем в заголовке
окна может быть стандартный значок вместо значка программы: так Qt5 работает
под Wayland, на работу это не влияет. Если мешает, запустите ее через X11:

```bash
QT_QPA_PLATFORM=xcb ./polygon-legacy
```

Файл без расширения. Если он пришел архивом или с сетевой папки Windows, право
на выполнение теряется - верните его и запустите:

```bash
chmod +x polygon
./polygon
```

Qt лежит внутри файла, но окну нужны системные библиотеки графики. На
компьютере с рабочим столом они обычно уже стоят. Если программа не
запускается и пишет, что не может загрузить плагин Qt «xcb», поставьте их - в
Debian и Ubuntu так:

```bash
sudo apt install libgl1 libxkbcommon-x11-0 libxcb-cursor0
```

В каждой программе есть кнопка «Справка» с порядком работы и описанием всех
параметров и кнопка «О программе» с номером версии.
