# lmoToXY

**Построение слоистой модели верхней части разреза по первым вступлениям для
параметризации модулей расчета статических поправок Refraction Miser или
Refraction Tomo**

Утилита формирует слоистую модель верхней части разреза на основе данных первых
вступлений. Входные данные - файл LMO из программы PickWorks: на каждом пункте
возбуждения (ПВ) программа определяет границы слоев в удалениях и рассчитывает
скорости слоев.

Координаты X/Y берутся из файла SPS. По результатам обработки формируются два
выходных файла:

- файл с удалениями слоев - для расчета статических поправок по первым
  вступлениям;
- файл со скоростями слоев.

## Входные данные

**Файл LMO** состоит из блоков строк, по одному блоку на ПВ. Колонки разделены
табуляцией: номер ПВ, минимальное удаление, максимальное удаление, время
интерсепта в мс и скорость в м/с. Номер ПВ указывается только в первой строке
блока; в остальных строках эта колонка пустая, и строка начинается с табуляции:

```
1001101	1.0	238.8	0.00	620.0
	238.8	1305.6	255.00	1835.1
	1305.6	1.0E7	575.67	3341.0
```

Такие данные копируются из программы PickWorks после пикировки LMO и
сохраняются в текстовый файл как есть: колонки должны остаться разделенными
табуляцией.

Строки одного блока - это участки одного непрерывного годографа первых
вступлений: время в конце участка совпадает со временем в начале следующего.

**Файл SPS** содержит записи ПВ с фиксированными позициями символов: линия ПВ -
позиции 2-17, точка ПВ - 18-25, X - 47-55, Y - 56-65. Линия и точка склеиваются в
номер ПВ, который должен совпадать с номером в файле LMO. Если в вашей партии
колонки или позиции другие, их можно изменить в окне «Колонки и позиции».

## Расчет

Каждый участок годографа относится к тому слою, в диапазон скоростей которого он
попадает. Диапазоны задаются таблицей; по умолчанию слоев три: 400-1200,
1200-2200 и 2200-5600 м/с. Границы слоев подбираются одним из двух способов:

- **МНК** - годограф приближается ломаной, по одному прямому отрезку на слой;
- **порог по скорости** - граница проводится там, где кажущаяся скорость
  пересекает середину промежутка между диапазонами соседних слоев.

Число слоев на всех ПВ одинаковое. Если какого-то слоя на ПВ в данных нет, он
заполняется окном шириной в шаг округления, по соседним ПВ или подбором всеми
слоями - способ выбирается в настройках. Расчет идет в фоне, ход работы и итоги
выводятся в журнал.

## Результат

Программа пишет два файла - в выбранный каталог вывода или рядом с файлом LMO.
Данные в них идут блоками по слоям:

```
<имя>_offset.txt:    <слой> <X> <Y> <мин.удаление> <макс.удаление>   со слоя 2
<имя>_velocity.txt:  <слой> <X> <Y> <скорость>                       со слоя 1
```

Файл удалений начинается со второго слоя, файл скоростей - с первого.

Если в одном каталоге лежат результаты нескольких проектов, кнопка «Объединить»
собирает их в один файл `_offset` и один `_velocity`. Точки, повторяющиеся по
координатам, при этом пропускаются.
