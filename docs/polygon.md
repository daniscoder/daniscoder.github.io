# polygon

**Построение полигона границы съемки**

Утилита формирует границу площади работ на основе выгрузки бинов или
произвольного набора точек, например данных SPS. Из выбранных колонок X и Y (как
правило, в метрах) строится замкнутый полигон.

Поддерживаются два режима построения:

- без отступа - контур, проходящий по крайним точкам съемки;
- с отступом - контур с буферной зоной, смещенной наружу от площади.

Если съемка состоит из нескольких отдельных площадей, например двух участков в
километре друг от друга, программа находит их сама и строит полигон на каждую.
Каждый полигон записывается в свой файл, а для Surfer все они собираются в один
файл BLN. При построении с отступом площади, между которыми меньше двух отступов,
сливаются в одну.

Полученный полигон используется в дальнейшей обработке в качестве границы съемки.

## Входные данные

На вход подается текстовая выгрузка бинов (CMP_info) или точек, например SPS:
строка заголовка и строки данных, колонки разделены пробелами. Колонок может быть
сколько угодно - программа разбирает только две выбранные. По умолчанию это
XCORD_CELL_CENTER и YCORD_CELL_CENTER, а если таких нет - x и y.

## Как строится контур

**Бины на регулярной сетке.** Сетку программа находит по самим точкам, поэтому ни
ординаты, ни угол поворота съемки ей не нужны. Кромка площади обходится бин за
бином, и в файл попадают координаты самих крайних бинов. Изрезанный край
обходится как есть, без сглаживания.

![Рваный край: synth_bins_regular.txt, отступ 30 м](img/polygon_regular.png)

**Точки не на сетке** - SPS, профили, съемки с разным шагом. Точки соединяются в
треугольники, и треугольники со стороной длиннее **разрыва** отбрасываются;
оставшиеся и образуют площадь. Разрыв подбирается по данным («авто») или
задается вручную: меньшее значение ведет контур ближе к точкам, большее срезает
выступающие углы и сливает близкие площади. Вогнутые углы, которые триангуляция
срезает наискось, спрямляются; насколько сильно - задает поле «Спрямление».

## Отступ

При нулевом отступе контур проходит по крайним точкам. Если отступ больше нуля,
строится буфер: площадь расширяется наружу на величину отступа, все точки
оказываются целиком внутри, а углы буфера остаются прямыми. Буферы площадей,
между которыми меньше двух отступов, сливаются.

Иллюстрации на этой странице сделаны с отступом 30 м.

## Результат

На каждую площадь строится свой полигон, они нумеруются от большой площади к
малой. Для координат X, Y рядом с входным файлом появляется файл
`<имя>_polygon.txt`, а если площадей несколько - по файлу на полигон:
`<имя>_polygon_1.txt`, `_2.txt` и так далее. Для Surfer записывается один файл
`<имя>_polygon.bln` со всеми полигонами.

![Две площади: synth_bins_two_areas.txt, два полигона](img/polygon_two_areas.png)

В конце работы программа сообщает площадь каждого полигона и показывает их на
картинке вместе с точками. Дыры внутри площадей в полигоны не включаются, их
число тоже указывается в итоге.

![Дыры внутри площади: synth_bins_hole.txt, полигон по внешнему краю](img/polygon_hole.png)
